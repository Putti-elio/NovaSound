How to read this page

Every value keeps its grain, unit, and limits.

Time comes from ms_played, not catalog duration. Days follow Europe/Paris. Missing values are excluded from their denominator and never become zeros.

View the metrics dictionary
  • Included stream: event of 30 seconds or more, not skipped.
  • Completion: listening time divided by catalog duration, capped only for display.
  • Active day: day containing at least one included event.

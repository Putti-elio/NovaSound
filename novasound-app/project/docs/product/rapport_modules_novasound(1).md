# Rapport fonctionnel des modules NovaSound

Ce document inventorie les modules visibles dans le whiteboard Canva NovaSound. Chaque page possède son propre tableau afin d’éviter les répétitions. La colonne **Conserver ?** permet de sélectionner les informations à maintenir dans la future interface : remplacer `[ ]` par `[x]`.

## Points à confirmer

- Les libellés exacts des périodes disponibles dans chaque sélecteur.
- Les métriques obligatoires : lectures, minutes, ou les deux.
- Le niveau de visibilité des statistiques de profil public.
- Les plateformes de partage réellement prises en charge.
- La destination exacte du signalement de données incorrectes.
